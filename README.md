# ReportPalette 

**ReportPalette** — это удобный пользовательский графический интерфейс (палитра быстрого запуска) для взаимодействия с системой **ManagerDataBase** и управления произвольными приложениями. Программа работает в фоновом режиме и вызывается глобальной горячей клавишей, экономя время при повседневной работе с отчётами и инструментами.


## Основные возможности

- **Мгновенный вызов**: Глобальный хоткей (по умолчанию `Ctrl+Alt+Q`) для открытия палитры поверх всех окон.
- **Панель запуска**: Быстрый запуск часто используемых программ с настраиваемыми аргументами командной строки.
- **Поддержка плагинов**: Интеграция внешних скриптов и утилит (Python, PowerShell, EXE) прямо в палитру с возможностью перехвата и отображения их вывода.
- **Интеграция с ManagerDataBase**: Быстрый доступ к генерации производственных отчётов (1010/2012) по спискам ДСЕ через подключенный бэкенд.
- **Встроенный планировщик задач**: Автоматический запуск приложений, плагинов или отчётов по расписанию (единожды, с интервалом, ежедневно, еженедельно или при старте системы).
- **Умный перенос настроек (v2)**: Экспорт и импорт конфигурации через компактную хеш-строку с возможностью **селективного выбора разделов** (например, перенести только плагины и задачи, не трогая хоткеи) и режимом объединения или полной замены списков.

## Системные требования

- ОС: Windows 10 / 11
- Среда выполнения: .NET 10.0 Desktop Runtime (или новее)
- Для работы с отчётами: доступ к запущенному бэкенду ManagerDataBase (по умолчанию `http://127.0.0.1:8000/`)

## Установка и запуск

### Вариант 1: Готовая сборка (Рекомендуется)
1. Скачайте архив с последней сборкой из релизов или получите папку с программой у администратора.
2. Распакуйте архив в удобную директорию (например, `C:\ReportPalette`).
3. Запустите файл `HotkeyApp.exe`.
4. *(Опционально)* В настройках включите опцию «Запускать при старте Windows», чтобы палитра была всегда под рукой.

### Вариант 2: Сборка из исходного кода
Если у вас установлен [.NET SDK](https://dotnet.microsoft.com/download):
```bash
git clone -b work https://github.com/volnaogt-organization/ReportPalette.git
cd ReportPalette
dotnet build -c Release
```
Исполняемый файл будет находиться в папке `bin\Release\net10.0-windows\HotkeyApp.exe`.

## Руководство пользователя

### 1. Вызов палитры
Нажмите `Ctrl+Alt+Q` (или другую комбинацию, заданную в настройках), чтобы открыть палитру поверх любых окон. Нажмите `Esc` или кликните вне окна, чтобы скрыть её.

### 2. Добавление приложений и плагинов
Откройте окно настроек (кнопка ⚙):
- **Панель запуска**: Добавьте путь к `.exe` файлу и, при необходимости, аргументы командной строки.
- **Плагины**: Укажите путь к скрипту или программе. Вы можете выбрать среду выполнения (`python`, `powershell` или оставить пустым для `.exe`/`.bat`). 
  - Используйте шаблон `{query}` в поле аргументов, чтобы передавать в плагин текст, введённый в палитре.
  - Включите опцию «Перехватывать вывод», чтобы результат работы плагина отображался прямо в интерфейсе палитры.

### 3. Планировщик задач
Позволяет автоматизировать рутинные операции. В настройках перейдите в раздел «Задачи расписания»:
1. Нажмите «Добавить задачу».
2. Выберите **Тип действия**: запуск приложения, выполнение плагина (по его ключевому слову) или формирование отчёта бэкенда (1010/2012).
3. Настройте **Триггер**: 
   - `При запуске приложения` (startup)
   - `Ежедневно` / `Еженедельно` (с указанием времени)
   - `С интервалом` (например, каждые 60 минут)
4. Сохраните задачу. Она будет выполняться автоматически фоновой службой приложения, даже если главное окно палитры скрыто.

### 4. Перенос настроек на другой компьютер (Конфиг v2)
Настройка синхронизации стала гибкой и безопасной:
1. **Экспорт**: 
   - Откройте настройки → раздел «Перенос настроек».
   - Отметьте галочками только те разделы, которые хотите перенести (например, «Панель запуска» и «Плагины»).
   - Нажмите «Сгенерировать строку». Вы получите компактную строку вида `RP2.секции.Base64.Хеш`. Скопируйте её.
2. **Импорт**:
   - На новом компьютере откройте настройки → «Перенос настроек».
   - Вставьте строку и нажмите «Проверить».
   - Система покажет предпросмотр: какие разделы будут затронуты и сколько элементов в них содержится.
   - Выберите режим для списков: **Объединить** (рекомендуется: добавит новые записи, не удаляя старые) или **Заменить полностью**.
   - Нажмите «Применить».

> **Безопасность**: Каждая строка переноса содержит контрольную хеш-сумму (SHA256). Если строка была случайно изменена при копировании, программа предупредит о повреждении и не применит настройки.

## Файл конфигурации
Все настройки сохраняются в локальный JSON-файл:
`%APPDATA%\HotkeyApp\settings.json`

Ручное редактирование файла возможно, но для избежания ошибок формата рекомендуется использовать встроенный интерфейс переноса настроек.

## Частые вопросы (FAQ)

**В: Хоткей не срабатывает.**  
О: Убедитесь, что приложение запущено (проверьте трей Windows). Проверьте в настройках, не перекрывает ли комбинацию другая программа. По умолчанию используется `Ctrl+Alt+Q`, так как `Win+Space` зарезервирован системой.

**В: Плагин не выводит результат в палитру.**  
О: Убедитесь, что в настройках плагина включена галочка «Перехватывать вывод» (`captureOutput`). Для скриптов Python или PowerShell убедитесь, что они добавлены в системную переменную окружения `PATH`, или укажите полный путь к интерпретатору в поле "Среда выполнения".

**В: Как подключиться к бэкенду на другом сервере?**  
О: В настройках, в разделе «Адрес бэкенда», измените значение `http://127.0.0.1:8000/` на актуальный сетевой адрес вашего сервера ManagerDataBase.
